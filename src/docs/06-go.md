```sh
go get github.com/runtime-bridge/rbridge/pkg/bridge
```

`bridge.New` runs rbridge inside your process: no daemon, same configuration files, same audit log. `bridge.Connect` talks to a running daemon instead. Both satisfy `bridge.Client`, so code written against the interface works either way.

```go
type Client interface {
	Providers(ctx context.Context, refresh bool) ([]ProviderStatus, error)
	Run(ctx context.Context, t Task, opts ...RunOption) (Result, error)
	Open(ctx context.Context, t Task, opts ...RunOption) (*Session, error)
	Resume(ctx context.Context, id string, opts ...RunOption) (*Session, error)
	Sessions(ctx context.Context) ([]SessionRecord, error)
	Close() error
}
```

## A complete program

```go title="main.go"
package main

import (
	"context"
	"encoding/json"
	"fmt"
	"log"
	"os"

	"github.com/runtime-bridge/rbridge/pkg/bridge"
)

func main() {
	ctx := context.Background()
	b, err := bridge.New(ctx, bridge.Options{})
	if err != nil {
		log.Fatal(err)
	}
	defer b.Close()

	res, err := b.Run(ctx, bridge.Task{
		Workspace: "/home/me/src/app",
		Prompt:    bridge.Text("Which dependencies are out of date?"),
		Profile:   "observe",
	}, bridge.OnEvent(func(e bridge.Event) {
		if e.Type == bridge.EventMessageDelta {
			var d bridge.TextData
			if json.Unmarshal(e.Data, &d) == nil {
				fmt.Fprint(os.Stderr, d.Text)
			}
		}
	}))
	if bridge.CodeOf(err) == bridge.ErrProviderUnavailable {
		log.Fatal("no runtime is installed; run rbridge doctor")
	}
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(res.Output)
}
```

## Tasks

| Field | Meaning |
|---|---|
| `Workspace` | Absolute project path the runtime works in |
| `Prompt` | `bridge.Text("...")`, or content blocks |
| `Provider` | Runtime id; empty picks the first available one that meets `Requirements` |
| `Skills` | Skill ids to deliver for this session |
| `Requirements` | Capabilities the runtime must have, such as `bridge.CapStructuredOutput` |
| `Profile` | `observe`, `standard`, `controlled` or `custom` |
| `Sandbox` | `off`, `files` or `full` |
| `OutputSchema` | JSON schema; the answer arrives in `Result.Structured` |
| `MCPServers` | MCP servers to give the runtime |
| `Timeout` | Per turn |

## Options

| Option | Use |
|---|---|
| `bridge.OnEvent(func(bridge.Event))` | Receive every event as it happens |
| `bridge.WithApprover(func(ctx, bridge.ApprovalRequest) bridge.ApprovalDecision)` | Answer requests the profile leaves to you |
| `bridge.AllowAll()` | Allow every request the profile asks about (scripts, trusted settings only) |
| `bridge.WithProfile("controlled")`, `bridge.WithModel("haiku")` | Per call overrides |
| `bridge.WithMode("code")` | Start in a runtime session mode |
| `bridge.WithInput(func(ctx, bridge.InputRequest) bridge.InputResponse)` | Answer questions the runtime asks the user |

## Approvals

```go
decide := func(_ context.Context, r bridge.ApprovalRequest) bridge.ApprovalDecision {
	switch r.Kind {
	case "read", "search":
		return r.AllowOnce("my-app")
	case "execute":
		if strings.HasPrefix(r.Title, "go test") {
			d := r.AllowOnce("my-app")
			d.Remember = true // the same kind of request is allowed for the rest of the session
			return d
		}
	}
	d := r.RejectOnce("my-app")
	d.Reason = "not something this app allows"
	return d
}
res, err := b.Run(ctx, task, bridge.WithApprover(decide))
```

A remembered decision never overrides a policy denial.

## Sessions, modes and settings

```go
s, err := b.Open(ctx, bridge.Task{Workspace: repo, Provider: "opencode"}, bridge.WithMode("ask"))
if err != nil {
	return err
}
defer s.Close(ctx)

cur, modes, _ := s.Modes(ctx)    // runtimes without modes return ErrCapabilityUnavailable
fmt.Println(cur, modes)
_ = s.SetOption(ctx, "model", "large")

res, err := s.Prompt(ctx, bridge.Text("Explain the build"))
id := s.ID() // keep it to continue later with b.Resume(ctx, id)
```

## Skills from code

```go
rec, err := b.AddSkill(ctx, "/opt/my-app/skills/release-notes", false)          // copy into the library
rec, err = b.AddSkillFromGit(ctx, "https://github.com/org/skills", commit, "audit") // pinned to a commit
rec, err = b.AddSkillFromCatalog(ctx, "team:security-audit")                      // digest checked
_, err = b.SetSkillTrust(ctx, rec.ID, bridge.TrustReviewed)
```

## Through the daemon

```go
r, err := bridge.Connect(ctx, bridge.ConnectOptions{Client: "my-app"})
if err != nil {
	return err // bridge.ErrProviderUnavailable when no daemon runs
}
defer r.Close()
res, err := r.Run(ctx, task)
```
